# Crypto-Crisis-Analysis
Analytical project exploring Bitcoin's price volatility and drawdown during major global events (2019-2024).

# Bitcoin Crisis & Event Impact Analysis ₿📉

An end-to-end data analysis project investigating how Bitcoin reacts to global "Black Swan" events, including COVID-19, geopolitical conflicts, and major regulatory shifts.

![Analysis Chart](btc_event_analysis.png)

## 📂 Project Structure
- **/data**: Contains raw daily BTC prices and the calculated Event Impact Summary.
- **/notebooks**: Jupyter Notebook containing the data fetching, cleaning, and drawdown logic.
- **/src**: Utility scripts for data processing.

## 🚀 Key Insights
- **Highest Volatility:** The COVID-19 pandemic caused a -48.09% drawdown within 14 days.
- **Geopolitical Impact:** BTC showed varying levels of resilience during the start of the 2022 Russia-Ukraine conflict compared to local exchange collapses (FTX).
- **Institutional Effects:** "Sell the news" patterns were identified during the Bitcoin ETF approval and Coinbase IPO.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Matplotlib, yfinance, Scikit-Learn
- **Environment:** Jupyter Notebook
